  Every factor carries a hypothesis card stating an economic mechanism,
  the conditions under which it should persist, and what would falsify
  it. Registration fails without one.

  'plausible range' is the interval the factor's raw values are checked
  against before any cleaning. 'undefined' means no range has been
  declared -- NOT that the factor passed. An undeclared range is an
  unchecked magnitude, and the two states are printed differently for
  the same reason an unknown share count is null and not zero.

  'as-of held' is a check on this code: did every read return only
  filings that were already public on the day being forecast, including
  any reporting lag the factor declared? A VIOLATION here would void
  every number in the row.

  'status' is whether the factor produced a result at all. OK means the
  run completed; it does not mean the factor works. A FAILED row has no
  numbers because none were computed -- the run stopped at the check
  named in the status, and that row is excluded from every table below.
