# Presentation replay, not a new computation

This report renders the unchanged results from
[the de1e836 archive](../b_selected_200_rerun_20260909/demo_run.json).
No database was opened and no factor was recomputed for this directory.

[render_manifest.json](render_manifest.json) identifies both source files and
their hashes, extracted sections, rendering implementation and environment.
[replay_input.json](replay_input.json) preserves all original computation fields
and adds presentation inputs recovered from the original text. Coverage values
have only the precision printed in that text; unprinted columns are not recovered.
The original token stream was checked before adding local copies of the existing
sensitivity disclaimer. Source consistency is not proof of economic correctness.

The [scoped validation](../../../VALIDATION_20260912.md) distinguishes checked
archive metrics, missing raw-panel evidence, presentation and performance.
[Recovered runtime observations](../../../RUNTIME_OBSERVATIONS_20260912.json)
are explicitly later recovery, not original demo_run.json fields. No research
gate is promoted. The original CRLF archives remain unmodified; this rendering
uses LF and 84-column wrapping.
